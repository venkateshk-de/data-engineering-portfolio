## Running the Website Locally

### Prerequisites

* Node.js
* npm
* Git

### Clone the Repository

```bash
git clone https://github.com/venkateshk-de/data-engineering-portfolio.git
cd data-engineering-portfolio
```

### Install Dependencies

```bash
npm install
```

### Start the Development Server

```bash
npm run dev
```

Open the local address displayed by Next.js, typically `http://localhost:3000`.

### Production Build

```bash
npm run build
```

## Deployment

The portfolio is deployed using Vercel.

Changes pushed to the `main` branch trigger an automated production deployment through the GitHub integration.
